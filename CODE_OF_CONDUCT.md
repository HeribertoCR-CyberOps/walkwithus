# Code of Conduct

This project exists to protect children and the people who walk with them. We expect the same care in how we treat each other.

**Expected:** respect for every language, culture, faith and neighborhood; patience with first-time contributors; criticism aimed at ideas, not people; honesty about mistakes.

**Not tolerated:** harassment, slurs or demeaning jokes; sharing anyone's personal information; sexualized content of any kind; using this project to surveil, profile or target any person or community; sustained disruption.

**Enforcement:** report privately through the repository's security advisory form or to the maintainers. Maintainers may edit or remove content and restrict or ban participants. Reports are handled confidentially.

This code is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
