# Support

- **Someone is in danger:** call **911**. This software is not an emergency service.
- **Running a program:** read `docs/FOR-ORGANIZATIONS.md`, then open an *Organization* issue with your public website.
- **Something is broken:** open a *Bug report*. Never include real names, numbers or reference codes.
- **A translation is wrong:** open a *Translation correction*.
- **Security:** Security → *Report a vulnerability* (private).

Maintainers acknowledge security reports within 48 hours and other issues within a week.
